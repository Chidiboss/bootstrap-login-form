Bootstrap 5 Login Form

A responsive login page built with HTML and Bootstrap 5 for a class assignment. It uses an official Bootstrap sign-in template as a base, with custom changes to the logo, spacing, styling, and labels.

What I Changed?
 1. Logo: Swapped out the default Bootstrap icon for a custom logo.
 2. Spacing: Adjusted padding and margins around the form and inputs.
 3. Labels: Updated the input labels to match the new layout.
 4. Design: Tweaked the colors, borders, and button styles.

Built With
1. HTML5
2. Bootstrap 5

 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/Chidiboss/bootstrap-login-form.git
   ```
2. Open `index.html` in your browser.
